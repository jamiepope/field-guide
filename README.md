# Paris Field Guide

A mobile-first travel guide for our July 2026 trip to Paris.

## Project Structure

- `MASTER_ITINERARY.md` — Source of truth for the trip.
- `days/` — Daily itineraries in Markdown.
- `research/` — Research notes for attractions, restaurants and logistics.
- `templates/` — HTML templates.
- `assets/` — CSS, JavaScript and images.
- `docs/` — Generated static website.

## Workflow

1. Update `MASTER_ITINERARY.md`.
2. Update the corresponding day in `days/`.
3. Build the site.
4. Review.
5. Commit.

The itinerary drives the guide. The guide drives the website.
